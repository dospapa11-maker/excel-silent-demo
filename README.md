# ☕ Excel裏方サイレント集計 実験デモ（ベーカリーカフェ編）

note記事 **『Excelを開かせずに裏で集計させる──現場に渡す「ファイルを移してダブルクリック」という小さな工夫』** の解説用デモコードです。

「相手にExcelの画面を開かせずに、フォルダにファイルを置いてダブルクリックするだけで裏側で集計する」という現場UIの仕組みを手元で実際に体験できます。

---

## 📁 フォルダ構成

| ファイル名 | 役割 |
| :--- | :--- |
| **`売上データ_20261025.csv`** | カフェのPOSレジから出力された生データ（完全な架空のダミーデータ） |
| **`集計する.vbs`** | Excelを裏側（非表示）で自動起動して集計・整形するWindows標準スクリプト |
| **`README_お試し手順.txt`** | メモ帳ですぐ読めるお試し手順 |
| **`LICENSE`** | MITライセンス（商用利用・改変自由） |

---

## 🚀 使い方（3ステップ）

1. **`集計する.vbs`** をカチカチッとダブルクリックします。
2. 画面にはExcelのウィンドウは一切出ません。2〜3秒ほど待つと、**「【集計が完了しました！】」** という小さなメッセージが出ます。
3. フォルダの中に **`完成_売上集計表.xlsx`** が新しく出来上がります。  
   開いてみると、エメラルドグリーンのヘッダー、金額・数量書式、カテゴリ別のSUMIF集計表が完成しています。

### もう一度試したいときは？
出来上がった `完成_売上集計表.xlsx` をゴミ箱にポイッと削除して、再度 `集計する.vbs` をダブルクリックしてください。何度でも新しいファイルが出来上がる瞬間をお試しいただけます。  
（※ファイルを消さずにそのままダブルクリックしても、最新データで自動上書きされます）
