☕ VBScript 裏方サイレント集計 実験デモ（ベーカリーカフェ編）
================================================================================

【このデモで体験できること】
note記事『Excelを開かせずに裏で集計させる』で解説した、
「相手にExcelの画面を開かせずに、ダブルクリックだけで裏で集計する」
という現場UIの仕組みを、ご自身のPCで実際に体感していただけます。

--------------------------------------------------------------------------------
■ フォルダ内の構成ファイル
--------------------------------------------------------------------------------
1. 売上データ_20261025.csv
   → カフェのPOSレジから出力された生データ（完全な架空のダミーデータです）。
     ※このファイルは裏で読み込むだけで、直接編集・上書きはされません（無事です）。
     ※フォルダ内にあるCSVファイルを1つ自動検出して集計します。

2. 集計する.vbs  ★【これをダブルクリック！】
   → Windows標準のVBScriptです。
     Excelを画面非表示（Visible=False）で裏側起動し、
     自動でCSVを読み込み、数式やヘッダー装飾を施して
     「完成_売上集計表.xlsx」を作成して静かに終了します。
     （※安心のため、実行前に右クリック「編集」またはメモ帳で中身をご確認ください）

--------------------------------------------------------------------------------
■ お試し手順（たったの3ステップ）
--------------------------------------------------------------------------------
【ステップ①】
「集計する.vbs」をカチカチッとダブルクリックします。

【ステップ②】
画面にはExcelのウィンドウは一切出ません。
2〜3秒ほど待つと、「【集計が完了しました！】」という小さなメッセージが出ます。

【ステップ③】
フォルダを見ると、「完成_売上集計表.xlsx」が新しく出来上がっています。
ファイルを開いてみてください。綺麗なエメラルドグリーンのヘッダー、
金額・数量の書式、カテゴリ別のSUMIF集計表が完成しています！

--------------------------------------------------------------------------------
■ もう一度試したいときは？
--------------------------------------------------------------------------------
出来上がった「完成_売上集計表.xlsx」をゴミ箱に削除して、
もう一度「集計する.vbs」をダブルクリックしてください。
何度でも新しいファイルがポコンと出来上がる瞬間をお試しいただけます。
（※ファイルを消さずにそのままダブルクリックしても、最新データで自動上書きされます）
